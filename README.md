# Weather

A simple, Apple-style glassmorphic weather app powered by the free [Open-Meteo API](https://open-meteo.com/). Defaults to Boca Raton, FL, with city search.

Plain HTML/CSS/JS — no build step, no API key.

## Run locally

Open `index.html` in a browser.
